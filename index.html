How to use the map

Listen to the instructions
  1. ●
    Choose an MRT line

    Click a coloured line button to focus on that route.

  2. ♫
    Click a station name

    Click any station name directly on the map. It will be highlighted and its name will be read aloud.

  3. ●
    Follow the selected line

    The selected route stays fully visible in its original colour, while other lines fade into the background.

  4. ↗
    See the whole network again

    Click “Back to full MRT map” to return to all lines.
